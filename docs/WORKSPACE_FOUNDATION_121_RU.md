# Genesis121 — большая основа совместного Workspace

Этот патч сознательно НЕ регистрирует новый движок в существующем редакторе или сетевых обработчиках. Игровой интерфейс и активный Workspace112 продолжают работать как раньше. Следующий патч должен подключить перечисленные ниже механизмы единым этапом.

## Реализовано и проверяется отдельно

- Совместный текст: RGA с детерминированным порядком одновременных вставок, удалением через tombstone, повторной доставкой без повторного применения, отказом при отсутствующих зависимостях и защите от переиспользования идентификатора. Все позиции — Unicode code points, не UTF-16. Пакет атомарен. Стабильные якоря сохраняются при удалении символа.
- Авторство: диапазоны видимого текста с UUID автора. Это автор вставки, не криптографическое доказательство личности.
- Присутствие: цвет курсора, подпись, файл, якорь выделения, номер сообщения, TTL и очистка при отзыве доступа. Чужие закрытые файлы не раскрываются наблюдателю. Настоящую личность должен подставить серверный сетевой адаптер.
- Права: OWNER/MAINTAINER/DEVELOPER/REVIEWER/VIEWER; чтение, изменение, создание, удаление, восстановление, сборка, утверждение, публикация, участники, история. Ограничения по папкам и видимости панелей. Minecraft OP не является полномочием. Убрать чтение означает также запретить действия с содержимым. Скрытая вкладка сама по себе не меняет права.
- Устойчивый журнал: один писатель, hash chain, force до подтверждения; обнаружение повреждения, удаление только неполного последнего кадра, отказ при испорченном полном кадре. Реальная отдельная JVM проверяет блокировку и сохранение после abrupt halt. Нет обещания сохранности при любой неисправности диска/питания.
- История: автор/ревизия/действие; восстановление текста и бинарных ресурсов; текущая ревизия обязательна при восстановлении, переименовании и замене бинарного файла. Старые состояния не исчезают при обычном перезапуске.
- Подтверждение удаления: короткоживущий серверный ticket на точный файл/хеш/ревизию/пользователя. Старый непроверенный delete API отклоняет запрос. Переименование не теряет текст и историю старого пути.
- Выпуски: неизменяемые байты, SHA-256, явный выбранный набор. Выбранные изменения накладываются на последний утверждённый набор, невыбранные остаются черновиками. Выбранное удаление явно убирает файл из следующего набора. Пустой выпуск отклоняется.
- Утверждение и сборка: проверяется актуальное право утверждающего и собирающего на все файлы; изменение прав аннулирует разрешение. Новые черновики не меняют уже утверждённые байты. Сам SHA не является подписью и не разрешает установку или публикацию на сервере.
- Обзор правок: добавлено/изменено/удалено и хеши до/после с фильтрацией по правам чтения.

## Границы первого backend

64 рабочих файла, до200000 текстовых узлов в документе, 4096 элементов в операции, 8MiB на кадр состояния, 256MiB на журнал, до64 участников. Состояние включает tombstone и утверждённые ресурсы: достижение лимита останавливает запись с ошибкой, не удаляет историю. Полные снимки упрощают восстановление, но не являются окончательной оптимизацией для длительных больших проектов. Ротация/компактация требует отдельного безопасного протокола.

Один пользователь пока должен иметь один упорядоченный генератор идентификаторов правок. Для двух независимых пишущих устройств одного аккаунта адаптер обязан ввести идентификатор реплики/выделение диапазонов; до этого второй писатель должен быть отклонён. Неизвестные зависимости нельзя молча пропускать — запросить повтор или снимок. Курсоры — временные данные, не сохраняются после перезапуска. Серверные роли независимы от Maop: право управлять сервером не даёт автоматически доступ к проекту.

Журнал имеет контроль целостности, но не защищает от владельца ОС, который перепишет весь журнал. Нет сетевой аутентификации в этих классах. Engine нельзя открывать по пути, присланному игроком: только по серверному project UUID в доверенном каталоге.

Кнопка боковой панели, вкладки и split-view редактора; транспорт операций/подписок/снимков; отображение чужих курсоров; импорт проектов112; локальная очередь несохранённых операций; Gradle/публикация84/наборы99/supervisor120. Нет обновления работающего мира, автоматического применения черновика или раздачи этого нового backend другим игрокам.

Точный план соединения сохранён в WORKSPACE_CONNECTION_PLAN_122.json. Промежуточный результат не должен показываться игроку как готовое совместное редактирование.

Проверка: `gradlew.bat workspaceFoundationChecks121`. Здесь выполнена отдельная компиляция JDK17 и проверки настоящих Java-файлов/дочерних JVM. Полная Gradle/NeoForge JDK21 и Minecraft не запускались.
