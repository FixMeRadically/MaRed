# Плавность общего Workspace и диагностика запуска сервера

- Чужие текстовые курсоры и стрелки мыши сглаживаются в каждом кадре. Две панели редактора хранят отдельные координаты сглаживания. Переход на другой файл, прокрутка и большие скачки позиции сбрасывают траекторию.
- Выделения участников рисуются только в видимой части редактора. Текст, индекс позиций Unicode и преобразование координат между общей и локальной версиями документа переиспользуются до изменения текста.
- Интервал подготовки и отправки правок сокращён со 100 до 50 мс. Подтверждение сервером, очередь правок и ограничения прав сохранены. Фактическая задержка также зависит от сети и времени записи на сервере.
- Владелец папки сервера повторно читает подписанный отчёт, когда процесс уже завершился, чтобы сохранить причину ошибки, появившуюся одновременно с завершением. Если запись журнала прервётся до готовности, владелец больше не ждёт до истечения тайм-аута запуска.

На Java прошли проверки производительности Workspace, синхронизации, очередей и Unicode. Серверная проверка использует моделируемые состояния процессов. Плавность в двух полноценных клиентах и все варианты запуска на Windows отдельно не измерены. Полную компиляцию мода в текущей среде остановила загрузка Gradle 8.14.5.

Для прогона в игре открой один и тот же большой файл на двух машинах, попробуй быстрый ввод, выделение и движение мышью, затем повтори с двумя панелями. Для проверки сервера запусти его штатно, дождись готовности и проверь обычный вход и перезапуск после сохранения мира.
