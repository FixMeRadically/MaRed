# MaRed / Genesis — seamless-transition-11

Накопительный патч поверх этапов 05–10. Включает исправления завершения supervisor из 10, работу с проектами и миром из предыдущих этапов.

## Изменения 11

Внешний переход больше не использует диалог 560×420, рамку и системный шрифт. Перед закрытием клиент сохраняет координаты и размер своего окна, fullscreen, размер Minecraft GUI и начало анимации. Supervisor открывает неактивируемую поверхность без рамки и кнопки на панели задач: для fullscreen — на весь соответствующий монитор, для оконного режима — в записанной области игры. Буфер отрисовки имеет разрешение GUI; увеличение — nearest-neighbor. Фаза Core сохраняется при переходе из Minecraft к supervisor. Появление маленького окна загрузчика прикрывается этой поверхностью.

Core использует пиксельные линии и текст без сглаживания. Пока игрок находится в мире, отдельный поток заранее экспортирует доступные bitmap-глифы активного ресурспака, а ширина символов берётся из Minecraft. При отсутствии экспорта используется встроенный пиксельный шрифт с кириллицей. Произвольные TTF/unihex-провайдеры и все варианты фильтров ресурспаков не поддерживаются этим экспортом: для отсутствующих символов действует fallback. Системный шрифт больше не используется.

Новая игровая JVM получает сохранённую область окна. При fullscreen применяется borderless-переход без смены разрешения рабочего стола; F11 возвращает декорации при выходе в оконный режим. Нативное раннее окно NeoForge создаётся до этого client-mixin: его скрывает внешняя поверхность. Это визуальное перекрытие двух процессов; непрерывное владение одним OS-окном здесь не реализовано. Настоящее переключение фокуса и смешанный DPI на нескольких мониторах требуют проверки на Windows.

Поверхность находится поверх окон до готовности мира/главного меню. Её можно скрыть правым кликом либо крестиком справа сверху, не прерывая запуск. Отметка готовности передаётся также через heartbeat, поэтому потерянный HTTP-запрос не должен оставлять анимацию поверх уже готовой игры. При завершении supervisor окно уничтожается.

## Что ускорено

- После подтверждённого выхода игровой JVM supervisor перестаёт ждать остаток restart grace budget живого Gradle/launcher. При недостаточных данных о выходе защитное ожидание сохраняется: второй клиент не запускается поверх непроверенного первого.
- После явного handoff commit подготовка следующего запуска начинается параллельно закрытию прежней игры. Установка JAR остаётся после завершения игры.
- Capture прямого запуска разрешает абсолютный executable через Gradle Java toolchain, если ранний commandLine содержит относительный `java`. При подходящем кэше следующий restart обходит Gradle; при отказе кэша причина теперь попадает в supervisor.log.
- Убрана дополнительная задержка скрытия внешнего перехода после ready. Экспорт шрифта выполняется заранее, а не на пути перезапуска.

**Ускорение 24→8 секунд пока не измерено и не подтверждено.** Холодный запуск новой JVM, NeoForge, ресурсов и мира остаётся. Чтобы выбрать следующее изменение по реальному узкому месту, добавлен компактный отчёт, отделяющий эти стадии от launcher и shutdown. Синтетические проверки ниже не являются замером Minecraft.

## Установка

Закрой тестовую игру и supervisor. Распакуй комплект и запусти `apply.cmd`: он использует прежний путь `%USERPROFILE%\Desktop\MappetPort\MaRed`. Для другого пути используй команду ниже. Установщик проверяет все затронутые файлы до записи, сохраняет backup и отказывается заменять неизвестные локальные правки. Вариант вручную из папки комплекта:

```powershell
py .\patch\apply_changes.py "$env:USERPROFILE\Desktop\MappetPort\MaRed" --check
py .\patch\apply_changes.py "$env:USERPROFILE\Desktop\MappetPort\MaRed"
```

Затем из MaRed, JDK 21:

```powershell
.\gradlew.bat --stop
.\gradlew.bat clean build
.\gradlew.bat runClient
```

Пересобрать нужно и основной мод, и вложенный supervisor-bootstrap: `clean build` делает это вместе. Запущенный старый supervisor не обновляется от замены исходников. Ручные command.N, workDir и настройки активация сохраняет.

Откат при закрытых игре и supervisor:

```powershell
py .\patch\apply_changes.py "C:\путь\к\MaRed" --restore "C:\путь\к\MaRed-supervisor-backup-..."
```

## Проверка и замер

1. Войди в мир, дай игре несколько секунд для фонового экспорта шрифта. Примени изменение. Проверь fullscreen и отдельно оконный режим: размер перехода, отсутствие рамки, шрифт, исчезновение после возврата в мир, F11.
2. Выполни ещё один restart: первый переход после чистой сборки может заполнить direct-launch cache. Сравнивай одинаковый мир и одинаковое изменение.
3. Из корня MaRed выполни и пришли вывод:

```powershell
py .\tools\restart_last.py .
```

Поля: `presentation_total_ms` — от появления Core до ready; `total_ms` — цикл supervisor; `launch_mode` — direct_cache/direct_config/gradle; `shutdown_ms`; `prepare_ms_parallel`; `spawn_ms`; `launcher_gap_ms`; `jvm_to_mod_loaded_ms`; `resources_and_menu_ms`; `world_load_ms`. Подготовка может перекрываться с закрытием, поэтому все поля нельзя просто складывать. Пустое поле означает отсутствие измерения. При старых логах режим может быть unrecorded. Незавершённый цикл не считается успешным.

Если launch_mode остаётся gradle, приложи строку причины отказа fast-launch из `run/client/config/mared/dev/logs/supervisor.log`. Не присылай supervisor.properties или полный launch command: там могут быть token и приватные аргументы.

4. Обычное закрытие игры должно завершать supervisor, а restart — возвращать игру. Проверь повторный запуск без ручной очистки порта:

```powershell
Get-NetTCPConnection -LocalPort 27670 -State Listen -ErrorAction SilentlyContinue
```

После завершения сессии вывод должен быть пустым. Если не так, нужны supervisor.log/bootstrap.log и время закрытия. Lifecycle остаётся version 10, новый presentationVersion — 11.

## Проверки комплекта

`py .\verification\run-checks.py` — 13 наборов JDK-only/process/API-adapter проверок на полном JDK 17+. Новые проверки покрывают roundtrip и срок жизни профиля окна, отрицательные координаты, синтетический 200% DPI, bitmap-протокол, пиксельную анимацию и reduced-motion, placement/F11, экспорт Latin/Cyrillic с doubles Minecraft/GLFW/Gson, разбиение таймингов и отказ неполных циклов. Реальная fake-game JVM подтверждает, что завершившаяся игра с оставшимся launcher не расходует весь restart grace budget. Проверки предыдущего lifecycle и накопительного installer/backup/restore сохранены.

Полная Gradle/NeoForge-сборка, Gradle capture hook, реальный Minecraft и headful Windows здесь не запускались. Client adapters типизируются с явно указанными API doubles; это не проверка binary compatibility. Успешный handoff и descendants помечаются SKIP, когда хост скрывает ProcessHandle metadata. Подробности и фактические логи находятся в verification.

`preview/restart-core-preview.gif` отрисован production painter с запасным пиксельным шрифтом. Реальный масштаб берётся из Minecraft GUI, а bitmap-шрифт при возможности — из ресурсов игры.
