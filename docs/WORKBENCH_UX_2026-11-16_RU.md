# MaRed. Навигация и клавиатура в рабочей области

Патч обновляет Studio, где находятся разделы Genesis, редакторы, проводник, вывод и справка. Он использует действия и поиск текущего проекта из MaRed.

## Чем руководствовался

| Наблюдение | Применение в MaRed |
|---|---|
| Видимое название действия помогает найти его мышью и запомнить клавишу. Grossman, Dragicevic и Balakrishnan исследовали связь между показом команд и обучением горячим клавишам. | Вынес доступ к действиям, поиску файла и поиску текста на верхнюю панель. В меню «Вид» есть команды смены фокуса с их сочетаниями. |
| Cockburn, Gutwin и Greenberg учитывают разные издержки визуального поиска, принятия решения и наведения указателя. | Оставил постоянный порядок меню и верхнюю строку текущего раздела. На узкой панели оставшиеся меню открываются через «…». Редко нужные команды доступны в поиске. |
| В рекомендациях W3C APG видимый фокус и предсказуемое перемещение рассматриваются отдельно от активации. | F6 переносит фокус между панелями без активации. Shift+F6 меняет направление. Выбранная панель получает контур. |
| В VS Code есть отдельные способы найти действие, открыть файл и искать текст проекта. | Ctrl+Shift+P, Ctrl+P и Ctrl+Shift+F выполняют эти операции в Studio. Верхняя строка MaRed дополнительно показывает направление и раздел Genesis. |

## Где искать

| Что нужно | Где находится | Клавиатура |
|---|---|---|
| Перейти в другой раздел текущего направления | Нажать верхнюю строку «Направление / Раздел» или выбрать раздел слева | Стрелки и Enter в открытом меню |
| Найти команду | «Действия» вверху справа, рядом со «Справкой» | Ctrl+Shift+P |
| Открыть файл по имени | «Найти файл» под строкой раздела в редакторе проекта | Ctrl+P |
| Найти текст по всему проекту | «Поиск по проекту» справа от поиска файла | Ctrl+Shift+F |
| Найти текст в текущей панели | Меню редактора или фокус в логах / справке | Ctrl+F |
| Открыть проводник и работать стрелками | «Вид → Фокус на проводнике» | Ctrl+Shift+E |
| Перейти к следующей или предыдущей панели | «Вид» | F6 / Shift+F6 |
| Открыть центр разработки | Разделы Genesis или клавиша из оболочки | Ctrl+Alt+D |
| Дублировать строки в классическом редакторе Commands | Действие редактора | Ctrl+Shift+D |
| Запустить или остановить текущую задачу | «Запуск» и элементы запуска над редактором | Ctrl+R / Ctrl+Shift+R |

Палитра принимает название действия, его идентификатор и текст сочетания клавиш. Можно ввести отдельные слова в другом порядке. Мышь подсвечивает строку под указателем, а Enter использует текущий выбор клавиш. Список можно прокрутить колесом; щелчок за пределами списка не активирует строку.

## Проверка в игре

1. Откройте «Моды → Скрипты» с двумя файлами. Проверьте поиск по имени, по тексту проекта и в текущем файле. Сверьте команды мыши с клавишами из таблицы.
2. Сверните проводник и нажмите Ctrl+Shift+E. Проверьте, что проводник раскроется. Переместитесь стрелками, затем F6 в редактор и Shift+F6 обратно.
3. Откройте палитру. Оставьте указатель над строкой, нажмите стрелку вниз и Enter. Должна выполниться выделенная клавиатурой команда.
4. Перейдите в «Серверы». Верхняя строка должна переключать только разделы этого направления. Проверьте верхнюю панель при уменьшенной ширине окна и увеличенном масштабе интерфейса.
5. В классическом редакторе Commands проверьте дублирование строки и открытие центра разработки разными сочетаниями. Проверьте Esc при открытом диалоге.

В среде подготовки JDK 21 разобрал три изменённых Java-файла, ключи русской и английской локализаций совпали, набор SyncChecks148 прошёл 49 проверок. Серверный Python-набор прошёл 1 164 теста. Gradle Wrapper не смог получить Gradle 8.14.5 из-за ограничения сети, поэтому полная компиляция клиентского мода и визуальная проверка в Minecraft ещё нужны. Сравнительный пользовательский тест удобства не проводился.

## Проход 02. Расположение действий с файлами

Над деревом появился заголовок «Проводник». Сворачивание находится справа в строке заголовка. Под ним расположены «+ Файл» и «+ Папка», когда проект поддерживает эти действия. Выбор папки в дереве задаёт место создания. Сужение панели заменяет подписи знаком «+» и пиктограммой папки. При минимальной ширине папка доступна через меню «Файл». В меню «Файл» сначала идут создание, сохранение и закрытие, затем операции с записями дерева и раскладка редактора.

Группировка по близости и общей области помогает связать кнопку с деревом, а модель Cockburn, Gutwin и Greenberg учитывает размер цели и время визуального поиска. Это основания для расположения, а фактическое удобство можно проверить повторным выполнением задачи в игре. Проводник VS Code служит ориентиром для группировки проектных операций.

Источники: [Proximity, NN/g](https://www.nngroup.com/articles/gestalt-proximity/) · [Common Region, NN/g](https://www.nngroup.com/articles/common-region/) · [Cockburn, Gutwin, Greenberg, CHI 2007](https://ir.canterbury.ac.nz/items/fd5ec0a7-03bf-4b08-a1a9-ba211be3d837) · [Интерфейс VS Code](https://code.visualstudio.com/docs/editing/getting-started/userinterface).

В игре проверьте создание файла после выбора корня и вложенной папки, минимальную ширину проводника, проект только для чтения и общий проект. Выполнены синтаксический разбор Java, проверка локализаций, расчёт на разных ширинах и 1 164 Python-теста. Полная сборка и проверка в Minecraft ещё нужны.

## Проход 03. Серверы и общий Workspace

В разделе управления сервером путь и состояние видны сверху. Следующая строка объединяет запуск или остановку с входом. Кнопка входа сохраняет позицию и включается, когда сервер готов. Ниже находятся применение проекта, папка и параметры подключения. В широком и узком окне позиции групп постоянны. У укороченных названий есть подсказки.

На главном экране Workspace добавлен отступ перед удалением. Пять обычных действий и маршрут подтверждения удаления сохранены. Нумерация убрана из названий, так как это разделы, которые можно открывать в любом порядке. В списке участников кнопки членства и прав остаются в строке игрока. На узком экране ширина списка уменьшается вместе с окном, а кнопка прав получает компактную подпись с подсказкой. Поиск фильтрует полученный список. Фоновый опрос обновляет элементы при изменении данных списка.

Проверены синтаксис трёх изменённых Java-файлов, обе локализации, 460 000 комбинаций размеров главного экрана Workspace и 1 164 теста Python. Проверка в Minecraft нужна для подписей при разных масштабах, повторного входа после смены статуса сервера и навигации по списку участников во время обновления.

## Единая раскладка

| Экран | Где искать действие | Управление клавишами |
| --- | --- | --- |
| Редактор, Проводник | Создание над деревом или в меню «Файл». Выбранная папка определяет место создания. | Справка открывается по F1, команды через Ctrl+Shift+P. |
| Справка по скриптам | Совпадения под строкой поиска, выбранная строка подсвечивается. | Стрелки и Enter. Esc сначала закрывает поиск. |
| Настройки | Разделы слева, при узком окне сверху. Отмена и сохранение справа внизу. | F6 открывает выбор раздела, Ctrl+Tab переключает разделы, Ctrl+S сохраняет. Поле назначения клавиши получает ввод первым. |
| Диалог имени | Поле, дополнительный флажок и нижняя строка действий. | Tab и Shift+Tab обходят элементы. Esc отменяет. Enter выполняет сфокусированное действие или подтверждает введённое имя. |
| Выбор папки | История и переход вверх рядом с адресной строкой. | Ctrl+L вводит путь, Alt+← и Alt+→ листают историю, Alt+↑ переходит в родительскую папку, Ctrl+Enter подтверждает выбор. |
| Сервер, подключение | Параметры разбиваются на страницы при малой высоте. Черновик сохраняется между страницами. «Назад» слева, «Сохранить» справа внизу. | Ctrl+S сохраняет. |
| Применение проекта | Выбор области сверху, прокручиваемое состояние в центре, подготовка и запуск внизу. Запуск доступен после подготовки. | Действия используют стандартную навигацию кнопок Minecraft. |
| Workspace | Действия с участником размещены в его строке. В форме прав «Назад» слева, сохранение справа. | Фильтр конфигураций сервера по Ctrl+F, сохранение по Ctrl+S. |
| Центр разработки | Вход из оболочки и выход из центра используют одну комбинацию. | Ctrl+Alt+D. |
