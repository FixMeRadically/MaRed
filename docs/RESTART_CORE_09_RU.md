# MaRed / Genesis — restart-core-09

Накопительный патч поверх этапов 05–08: ускоренный повторный запуск и анимация Core во время перезапуска. Включает функционал 06/07/08. Установщик сохраняет резервную копию и отказывается заменять неизвестные локальные правки.

## Что изменилось

- При сохранении мира перед автоматическим применением появляется Core из Genesis: используются настоящие GenesisCoreRenderer и GenesisCamera. Overlay не закрывает редактор и не отменяет применение мода.
- После запроса supervisor показывает собственное небольшое окно с четырьмя кольцами, вращающимся октаэдром и пульсирующим ядром. Оно продолжает анимацию в промежутке между JVM Minecraft. Это окно того же supervisor, отдельный процесс для анимации не создаётся.
- Подписи показывают реальные этапы: завершение игры, подготовка файлов, запуск Minecraft, ресурсы, открытие мира, восстановление игрока. Нет выдуманных процентов или задержки ради анимации.
- После готовности мира или главного меню окно скрывается. При отказе загрузки/отмене оно также убирается. Обычное закрытие игры, ошибка запуска и завершение supervisor освобождают окно и таймеры.
- Закрытие крестиком скрывает только анимацию; сам перезапуск продолжается. Окно не захватывает фокус и не закрепляется поверх остальных окон. В headless-среде или без java.desktop перезапуск работает без окна.
- Для стандартного `gradlew[.bat] --no-daemon runClient` появился быстрый путь: Gradle сохраняет фактическую команду JavaExec, рабочий каталог и изменения окружения. Supervisor проверяет её и запускает клиент напрямую, минуя повторные wrapper/daemon/configuration/task checks.
- Кэш ограничен 24 часами, проверками наличия Java и каталогов, отпечатками исходников, сборочных файлов, compiled outputs, classpath и native paths. Изменённый/повреждённый кэш, неизвестная конфигурация, превышение бюджета и debug-запуск оставляют обычный путь. У JAR проверяются путь, размер и mtime; небольшие исходники/outputs хешируются по содержимому. Сканирование ограничено 2 с / 96 МиБ / 30 000 записей.
- Длинная команда Java на Windows использует собственный временный @argfile; кириллица, кавычки, пробелы и пустые аргументы сохраняются. Временные Gradle @argfiles копируются до их удаления Gradle.

Сборка импортированного мода, проверка JAR/provenance, сохранение мира и checkpoint игрока остаются частью применения. Ускоряется запуск основного клиента после них. Если настроена собственная команда с дополнительными задачами/флагами, она выполняется как прежде. Если клиент уже запускался напрямую, исключать Gradle ему и раньше не требовалось.

DevActivationService и исправленные файлы подключения этот этап не заменяет. В существующем supervisor.properties сохраняются пользовательская команда и настройки. Первый запуск после установки должен пройти через Gradle, чтобы собрать новый bootstrap и записать кэш. Если он не может быть записан, используется прежний запуск.

## Установка

Закрой игру и старый supervisor. Распакуй архив. Для прежнего пути можно запустить `apply.cmd`, либо выполнить из распакованной папки:

```powershell
py .\patch\apply_changes.py "$env:USERPROFILE\Desktop\MappetPort\MaRed" --check
py .\patch\apply_changes.py "$env:USERPROFILE\Desktop\MappetPort\MaRed"
```

Затем из папки MaRed с JDK 21:

```powershell
.\gradlew.bat --stop
.\gradlew.bat clean build
.\gradlew.bat runClient
```

Уже установленные изменения пропускаются. Если preflight сообщает `Base differs`, ничего не меняется: не копируй файлы поверх своих правок вручную. Путь к резервной копии печатается при успешной установке. Повторный запуск установщика идемпотентен.

Для отката при закрытых игре и supervisor:

```powershell
py .\patch\apply_changes.py "C:\путь\к\MaRed" --restore "C:\путь\к\MaRed-supervisor-backup-..."
```

## Проверка в игре

1. Запусти `runClient` после сборки, войди в приватный одиночный мир, включи supervisor прежним способом.
2. Выполни успешное применение небольшого изменения импортированного мода. Во время checkpoint должен появиться Core. После закрытия Minecraft анимацию продолжает окно Genesis.
3. Проверь восстановление мира/игрока и исчезновение окна после готовности. Повтори перезапуск.
4. В `run/client/config/mared/dev/logs/supervisor.log` строка `[fast-launch] Validated captured JVM command; skipping Gradle wrapper and daemon` подтверждает использование быстрого пути. Отсутствие строки означает прежний/уже прямой запуск; проверь также сообщение о недоступном кэше.
5. Сравни реальные измерения до/после через `py tools/restart_report.py --help` и существующий отчёт timings.jsonl. Первую Gradle-сессию отделяй от повторных перезапусков.
6. Измени исходники самого MaRed либо build.gradle: следующий wrapper-запуск должен снова пройти через Gradle. Изменение импортированного мода в `mods` не требует пересборки MaRed и само по себе не отключает быстрый путь.
7. Закрой игру обычным способом: supervisor должен завершиться без повторного запуска и без оставшегося окна. Крестик окна анимации не является отменой перезапуска.

`preview/restart-core-preview.gif` — предпросмотр, отрисованный production Java2D-кодом supervisor. Он иллюстрирует вид; надпись/время в настоящем окне берутся из текущего перезапуска.

## Дополнительные настройки

Необязательно, в `run/client/config/mared/dev/supervisor.properties`, при закрытом supervisor:

```properties
fastLaunch.enabled=true
restartUi.enabled=true
restartUi.reducedMotion=false
```

`fastLaunch.enabled=false` оставляет обычный настроенный запуск. `restartUi.enabled=false` отключает внешнее окно. Для уменьшенного движения во внешнем окне поставь `restartUi.reducedMotion=true`; внутриигровая анимация использует существующую настройку Genesis. По умолчанию быстрый путь и внешнее окно включены.

## Что проверено здесь

JDK-only supervisor с настоящими дочерними JVM/HTTP/файлами; кэш запуска и fallback; @argfile; сохранение редактора и очистка overlay на ошибках с явно подменённым API игры; отрисовка 90 кадров; прежние lifecycle/trial/deployment/profile/background/report сценарии; типизация полного настоящего Genesis core вместе с background adapter; установка 05/06/07/08 с LF/CRLF, повторная установка, откат и защита локальных правок.

Полная Gradle/NeoForge-сборка, выполнение нового Gradle capture hook, настоящее окно Swing на Windows и измерение времени реального Minecraft здесь не выполнялись: доступен JDK 17 без игровых зависимостей. Снижение секунд/процентов не заявляется. Проверки handoff/descendants помечены SKIP, когда среда скрывает ProcessHandle metadata. Подробности и логи в `verification`.
