# MaRed. Восемь исправлений, подтверждённых тестами

Каждый сценарий воспроизведён на коде предыдущего патча. С новыми правками прошли все 1191 тест серверного набора.

| Сбой до исправления | Что проверяет тест |
| --- | --- |
| При падении после начала загрузки мира Bootstrap возвращал старый JAR и при повторном запуске мог продолжить восстановление. | `test_failed_world_loading_keeps_trial_jar_for_review_and_next_start` проверяет, что пробный JAR и журнал остаются на месте, а повторный старт ждёт разбора. |
| При остановке сервер мог отклонить сохранение, если первое чтение вернуло старую квитанцию `STOPPED_SAVED`, а нужная появилась к моменту выхода. | `test_stop_reads_matching_receipt_after_exit_even_if_first_is_stale_saved` проверяет повторное чтение и совпадение команды. |
| Недоступность диагностического журнала `update115.json` превращала успешно применённое обновление в ошибку. | `test_diagnostic_write_failure_does_not_stop_applied_server` проверяет, что обновление остаётся завершённым, новый JAR остаётся на месте, сервер не уходит в ожидание остановки. |
| Устаревшее представление раунда могло инициировать `COMMIT` после подписанной отмены релиза. | `test_terminal_rollout_beats_stale_preparing_view` проверяет, что отмена завершает задание и `COMMIT` не отправляется. |
| При восстановлении после записи `COMMIT_PENDING` очередь могла уже перейти к другой команде, хотя владелец подтвердил нужный `COMMIT`. | `test_interrupted_enqueue_recovers_from_owner_receipt_after_queue_advanced` проверяет восстановление по подписанному ответу владельца без повторной отправки. |
| Ошибка сохранения старого сервера записывалась как начало загрузки мира кандидата, который ещё не запускался. | `test_failed_save_does_not_mark_a_candidate_world_as_loaded` проверяет, что сохраняется причина `UPDATE115_SAVE_UNCONFIRMED` и журнал остаётся в `PREPARED`. |
| Повреждённая вторая копия JAR обнаруживалась только после замены первого файла. | `test_corrupt_second_payload_leaves_every_live_jar_unchanged` проверяет, что изменения не начинаются при повреждённом наборе. |
| Ошибка записи `logs/status.json` прерывала работу владельца после публикации подписанного состояния. | `test_owner_keeps_publishing_after_optional_status_log_fails` проверяет, что отчёт владельца завершается и подписанные данные остаются доступными. |

Архив включает файлы предыдущего патча серверной части и Workspace. Старый перечень из 50 пунктов не входит в этот архив. Живой запуск Minecraft и Windows Job не выполнялся.
