Управление без подтверждения сохранения

Обычный перезапуск запрашивает остановку процесса и запускает его повторно. Подтверждённый результат сохранения игры не проверяется.

Требуется проверка состояния

Новый сервер не запускается поверх прежнего. Принудительная остановка может потерять несохранённый прогресс. Подтверждение проверки не восстанавливает и не проверяет мир.
